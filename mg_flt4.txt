# 数学ガールの証明

（見直すこと）

## ピタゴラ・ジュース・メーカー

原始ピタゴラス数の生成式 (※) をこのように呼ぶ。

A^2 + B^2 = C^2 /\ A⊥B
<->
A = m^2 - n^2 /\ B = 2 * m * n /\ C = m^2 + n^2 /\ m > n /\ m⊥n /\ mとnの片方が奇数

これは同値変形であるとともに、``->`` において、mとnは一意に決まる。


## FLT の定義

n を 3 以上の自然数とする。

FLT(n) = forall x y z, x^n + y^n ≠ z^n


以降、FLTの否定で考えるので、扱う論理式は

P(n) = ~FLT(n) = exists x y z, x^n + y^n = z^n /\ x⊥y

また、次の条件から、等式が成り立つ場合について、x⊥y と x⊥z かつ y⊥z は同値


## 互いに素条件

x, y の公約数が d とする。
x^n + y^n = z^n が成り立つことと、両辺を d^n で割った式が成り立つことは同値である。
よって、x と y が互いに素 x⊥y である場合のみ考えればよい。



## ピタゴラス三角形との関係

三辺が自然数の直角三角形をピタゴラス三角形という。
面積が平方数のピタゴラス三角形が存在することと、P(4) が成り立つことは同値である。

証明：

P(4) を（※）で同値変形すると、以下を得る。

exists A B C D, A^2 + B^2 = C^2 /\ 2*A*B = D^2 /\ A⊥B



## 面積が平方数のピタゴラス三角形の不存在

面積は平方数のピタゴラス三角形が存在すると仮定すると、以下が成り立つ。

exists A B C D, A^2 + B^2 = C^2 /\ 2*A*B = D^2 /\ A⊥B

（※）使って同値変形すると、

exists A1 B1 C1 D1, A1^2 + B1^2 = C1^2 /\ 2*A1*B1 = D1^2 /\ A1⊥B1 /\ C1 < C

を得る。しかし、この無限降下は矛盾であるから、面積は平方数のピタゴラス三角形は存在しない。


## 結論

P(4) は成り立たない。よって FLT(4) は成り立つ。

## NumberTheory/FLT/Four.lean

- Fermat42 すなわち a^4 + b^4 = c^2 (仮定)
def Fermat42 (a b c : ℤ) : Prop := a ≠ 0 ∧ b ≠ 0 ∧ a ^ 4 + b ^ 4 = c ^ 2


- （Fermat42 を前提とした）無限降下法
def Minimal (a b c : ℤ) : Prop :=
  (Fermat42 a b c) ∧ (∀ a1 b1 c1 : ℤ, Fermat42 a1 b1 c1 → Int.natAbs c ≤ Int.natAbs c1)


- We can assume that a minimal solution to `a ^ 4 + b ^ 4 = c ^ 2` has `a` odd and `c` positive.
  （Fermat42 が成り立てば）無限降下できるという補題
theorem exists_pos_odd_minimal {a b c : ℤ} (h : Fermat42 a b c) :
    ∃ a0 b0 c0, Minimal a0 b0 c0 ∧ a0 % 2 = 1 ∧ 0 < c0



- 無限降下から偽を導く補題
theorem not_minimal {a b c : ℤ} (hm : Minimal a b c) (ha2 : a % 2 = 1) (hc : 0 < c) : False

hm : Minimal a b c
